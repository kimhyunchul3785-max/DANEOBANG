# 단어방 v5.2 로컬 스냅샷: UX/UI·IA 시각 QA

- **대상:** `C:\…\단어방\DANEOBANG` 현재 작업본(v5.2, 커밋되지 않은 변경 포함). 배포본·GitHub는 보지 않았습니다.
- **방법:** 로컬 스냅샷을 그대로 실행해 브라우저에서 역할별 주요 흐름을 직접 따라가며 캡처했습니다. 웹은 스크린샷 약 130장, 모바일은 약 50장입니다.
  - 역할: 원장(tester.owner), 선생님(tester.t1), 학생(tester.s01·s02·s05), 빈 상태 계정(owner@·teacher@·student@)
  - 폭: 웹 390 / 768 / 1024 / 1280 / 1360 / 1440 / 1920, 모바일 앱 390×844
- **모바일(apps/mobile):** 클라우드 복사본에서 Expo를 띄웠고, react-native-web으로 렌더링했습니다. 실제 Android·iOS 기기가 아니므로 네이티브에서만 생기는 문제(키보드, 안전 영역, 제스처 뒤로가기)는 확인하지 못했습니다.
  - 웹 렌더링용으로 복사본에만 두 가지를 손봤습니다. SecureStore 대신 localStorage를 쓰는 shim을 넣었고, API 호출은 CORS 프록시를 거치게 했습니다.
  - 사용자 폴더의 원본 코드는 수정하지 않았습니다.

## B. UX/UI: 웹

### P0
1. **모바일 웹에서 시험 만들기 2~5단계의 [다음] 버튼이 화면 밖에 있습니다.**
   - 현재: DAY를 고르면 미리보기 카드가 아래에 붙으면서 `action-bar`(sticky)가 문서 끝(y≈1340)으로 밀립니다. 설정도 `bottom:12px`, z-index 20이라서 붙어 있더라도 하단 탭바(49px, z-index 40)에 가려집니다.
   - 수정안: 모바일에서는 action-bar를 `position:fixed; bottom: calc(탭바 높이 + 8px + safe-area)`로 둡니다. 출제 흐름 동안 하단 탭바를 숨기는 방법도 됩니다(응시 화면처럼 '작업 모드'로). 미리보기는 모바일에서 접힘(펼쳐 보기)으로 바꿉니다.

### P1
2. **재시험 기능이 두 모델로 나뉘어 있습니다.**
   - 현재: 학생 상세에는 '반복 오답 12개 → 이 12개로 재시험 출제'(학생 단위 누적)가 있습니다. 그런데 같은 화면의 재시험 카드에는 "재시험 화면에서 범위·마감을 정해 내세요"라고 적혀 있습니다. 재시험 탭은 시험 단위 행마다 [오답만 n · 출제]를 둡니다. 같은 학생에게 두 경로로 중복 출제될 수 있습니다.
   - 수정안: 재시험 탭의 학생 그룹 헤더에 **'누적 오답으로 한 번에'**를 기본 CTA로 두고, 행 단위 출제는 [조정] 안으로 넣습니다. 학생 상세의 재시험 카드는 "재시험 탭 → 이 학생 필터" 링크 하나로 통일합니다.
3. **재시험 탭 행마다 빨간 CTA가 반복됩니다.**
   - 현재: 1024px에서도 행마다 `[출제 전] [오답만 n · 09/27까지 출제] 조정 · 재시험 없이 종료`가 붙습니다. 상단 '마감일별' 타임라인은 대부분 빈 점이고 1024px에서 잘립니다.
   - 수정안: 행 CTA는 회색 보조 버튼으로 두고, 그룹 헤더나 선택 후 하단 바에만 주 버튼을 둡니다. 타임라인은 재시험이 있는 날만 칩으로 보여 줍니다.
4. **학생 탭 한 화면에 역할이 다섯 개입니다.** 명단, 반 코드(꺼진 상태인데 주황 강조), 엑셀 등록, 한 명 등록, 반 관리가 한 페이지에 있습니다. 반 관리는 학원 설정 '반 관리' 탭에도 있습니다.
   - 수정안: 학생 탭은 명단만 둡니다. 우상단 [학생 추가]를 누르면 시트가 열리고 그 안에 '한 명·엑셀·반 코드 공유' 탭을 둡니다. 반 관리는 설정 한 곳에만 둡니다. 꺼진 반 코드는 회색 카드에 [켜기]만 두세요.
5. **성적의 '시험별' 탭이 시험별이 아닙니다.** 학생×시험 응시 로그 39행이 나열되고, 반별·기간 필터가 이 탭에서만 사라집니다.
   - 수정안: 시험 한 줄에 평균·통과율·미응시를 두고 펼치면 학생별로 보이게 합니다. 필터 바는 세 탭에서 같은 위치에 유지합니다.
6. **학생 화면에서 부모 표시가 어긋납니다.**
   - '연습'은 상위 탭인데, 모바일에서 열면 탭이 사라지고 '← 성적' 뒤로가기가 나옵니다.
   - 결과 화면은 '← 성적' 링크를 보여 주면서 활성 탭은 '이번 주'입니다.
   - 수정안: 연습에서는 탭을 유지합니다. 결과 화면은 들어온 곳(이번 주 또는 성적)을 `?from=`으로 받아 뒤로가기와 활성 탭을 맞춥니다.
7. **404·권한 없음 처리.**
   - 없는 시험·결과에 들어가면 Next 기본 흰 화면 404가 나오고 내비가 없습니다.
   - 선생님이 /app/teachers·/settings·/billing에 들어가면 **아무 안내 없이** /app으로 돌아갑니다.
   - 학생이 /app에 들어가면 /switch로 이동합니다.
   - 수정안: 앱 셸 안에 `not-found.tsx`를 두고 "시험을 찾을 수 없어요 → 시험 목록"을 보여 줍니다. 권한이 없으면 토스트 "학원장만 볼 수 있어요"를 띄웁니다.
8. **원장 요금제 화면에 개발자 문구가 보입니다.** '.env에 BILLING_ENABLED="true"를 넣으면…'
   - 수정안: 체험 중에는 "현재 무료 체험 중 · 선생님 4명 · 정식 요금 월 9,900원/명"만 보여 주고, 개발용 안내는 dev 빌드에서만 노출합니다.
9. **학생 홈 재시험 카드 레이아웃이 깨집니다.** 'RETAKE 준비 중'이 큰 숫자용 글꼴로 '준비 / 중' 두 줄이 되고, '할 일 2 · 완료 0'도 두 줄로 쪼개집니다.
   - 수정안: 값이 숫자가 아닐 때는 본문 글꼴로 한 줄 상태 칩을 씁니다.
10. **학생 결과(미달) 화면에 '다음 할 일'이 없습니다.** 데스크톱은 왼쪽에 결과 카드 하나만 있고 오른쪽에 오답 16개가 길게(2,800px) 이어집니다.
    - 수정안: 결과 카드 아래에 "재시험: 선생님이 준비 중 / 마감 ○일"과 [틀린 단어 연습]을 둡니다. 오답은 기본 5개만 보여 주고 더 보기로 펼칩니다.

## C. IA 점검: 부모→자식 구조와 중복 진입점

**부모→자식 구조가 자연스럽게 느껴지는 곳**
- 시험 상세 → 문항·정답(/items)·응시 대상(/targets): 브레드크럼, 뒤로가기, 활성 탭이 일관됩니다.
- 사진 채점: 시험 탭 아래로 옮겨 활성 탭이 '시험'이고, '← TESTS'로 돌아갑니다.
- 단어장 → '이 단어장으로 시험 만들기': 단어장을 고정하고 보던 DAY가 미리 선택되며, 뒤로가기하면 단어장으로 돌아옵니다.
- 출제 완료: 시험 상세로 이동하고 '발행했습니다 · 5명에게' 배너가 뜹니다. 여기서 뒤로가기를 누르면 빈 위저드로 돌아가서 중복 발행 위험은 없었습니다.

**부모가 흐리거나 진입점이 중복되는 곳**

| 기능 | 진입점 | 권장 |
|---|---|---|
| 재시험 출제 | 재시험 탭(행 단위) · 학생 상세(누적 오답) · 대시보드 '출제 전 14건' | 출제는 재시험 탭 한 곳. 나머지는 필터 링크로 |
| 반 관리 | 학생 탭 하단 · 학원 설정 '반 관리' 탭 · /app/classes → 학생 | 설정 한 곳 |
| 선생님 관리 | 사이드바 '선생님' · 학원 설정 '선생님' 탭 | 사이드바 하나로 두고 설정 탭은 제거 |
| 사진 채점 | 대시보드 상단 버튼 · 시험 목록 '사진 채점 →' · 시험 상세 종이 카드 | 대시보드 버튼은 확인 필요 건수가 있을 때만 |
| 틀린 단어 연습 | 학생 연습 탭 · 성적 'PRACTICE' 바 · 결과 화면 | 부모를 '연습'으로 통일하고 나머지는 딥링크 |
| 원장 '오늘' | 사이드바 라벨은 '오늘', 화면 제목은 '운영 현황' | 원장은 '현황'으로 라벨 통일, 본인이 가르치면 '내 할 일' 카드 추가 |
