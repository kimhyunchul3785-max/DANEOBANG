# 단어방 선생님 웹 — IA 재정의 v5 (2026-09-23)

목표: 화면을 줄이는 게 아니라 **부모→자식 위계로 나누고**, 한 화면에서 다른 영역으로 건너뛰는 링크(A→B, C→B)를 없앤다. 각 페이지는 부모 하나, 자식 몇 개, 그리고 "그 자리에서 끝나는 동작"만 가진다.

## 1. 현재 IA

```text
사이드바  오늘 · 학생 · 단어장 · 시험 · 성적 · 재시험 | 선생님 · 요금제 · 학원 설정

/app                      오늘 (대시보드)
/app/students             학생 명단 · 반 관리 · 등록 · 반 코드
  /app/students/[id]      학생 상세 (추이 · 반복 오답 → 재시험 즉시 출제 · 이력 · 정보)
/app/vocabulary           업로드 카드 + 단어장 카드 [시험 만들기] [열기] [보관] + 업로드 이력
  /app/vocabulary/[bookId]  단어장 상세: 원본 · SPLIT(DAY 나누기) · 이 단어장으로 만든 시험 · DAY 탭 + 단어 표
                          우측 상단 [DAY n 시험 만들기]  · DAY 섹션 안 [이 DAY로 출제]
  /app/imports/[id]       업로드 분석 상태 (끝나면 단어장으로 자동 이동)
/app/tests                시험 목록 [사진 채점] [+ 시험 만들기]
  /app/tests/new          출제 1화면: 1 범위(단어장 칩 + DAY 칩) 2 대상 3 조건 4 이름·공개 + 미리보기 → 동작 바 [초안만] [출제]
  /app/tests/[id]         시험 상세 3단계 탭: 1 단어 목록 점검 · 2 응시 대상 · 3 출제·진행 (마감 변경 · 종이 시험지 · 응시 현황) → 동작 바 [성적 보기 →]
  /app/scans, /app/scans/[id]  사진 채점 (시험 메뉴 활성)
/app/results              성적: 위젯 보드 · 학생별 요약 · 시험별 상세 (시험/반 선택 → [조회])
  /app/results/[attemptId]  응시 결과 (재채점 · 무효 · 오답노트 PDF)
/app/retakes              재시험 큐 (줄마다 오답만/같은 범위 · 마감 · [재시험 출제])
```

### 지금 화면끼리 건너뛰는 링크 (모두 "다른 영역의 깊은 페이지"로 간다)

| 출발 | 도착 | 종류 |
|---|---|---|
| 오늘 | `/app/tests/new`, `/app/results?filter=overdue`, `/app/scans` | 허브 → 다른 영역의 자식 |
| 단어장 카드 · 단어장 상세 ×2 | `/app/tests/new?bookId=…&day=…` | 단어장 → 시험 영역의 출제 화면 (같은 화면을 두 곳에서 다르게 진입) |
| 단어장 상세 "이 단어장으로 만든 시험" | `/app/tests/[id]` | 단어장 → 시험 상세 |
| 시험 상세 | `/app/results?examId=…#detail`, `/app/results/[attemptId]`, `/app/students/[id]`, `/app/vocabulary/[bookId]` | 시험 → 성적·학생·단어장 |
| 성적 위젯 · 상세 표 | `/app/tests/[id]?step=3`, `?step=3#due`, `/app/students/[id]` | 성적 → 시험 3단계 · 학생 |
| 학생 상세 이력 | `/app/results/[attemptId]`, `/app/tests/[id]`, `/app/results?student=` | 학생 → 성적·시험 |
| 재시험 큐 | `/app/results/[attemptId]`, `/app/tests/[id]?step=3`, `/app/students/[id]` | 재시험 → 성적·시험·학생 |

## 2. 문제점

1. **단어장 상세의 출제 흐름이 거꾸로** — 우측 상단 SPLIT 카드에서 나누기·적용 → 화면 아래 DAY 탭에서 DAY 고르기 → 다시 우측 상단 [DAY n 시험 만들기]. 시선이 위→아래→위. 게다가 같은 화면에 [이 DAY로 출제]가 하나 더 있어 출제 진입이 3곳(카드·상단·DAY 섹션).
2. **출제 화면이 하나뿐** — 시험 탭에서 들어오면 단어장부터 골라야 하는데 "1 범위" 안에 단어장 칩과 DAY 칩이 섞여 있고, 단어장에서 들어와도 단어장 칩이 그대로 보여 다른 단어장으로 바꿀 수 있다 (전제가 깨짐).
3. **발행된 시험을 열면 3단계 탭이 그대로** — 이미 출제된 시험인데 "1 단어 목록 점검 · 2 응시 대상"이 앞에 있고, 3단계에서 성적은 [성적 보기 →] 로 성적 탭으로 보내 버린다. 선생님이 시험 탭에서 원하는 건 마감·종이 시험지·지금 성적 요약 세 가지.
4. **성적 탭 상세는 [조회]를 눌러야** 렌더된다 (GET 폼). 선택 즉시 바뀌어야 한다.
5. **건너뛰기 링크가 영역마다** — 위 표처럼 성적·재시험·학생·단어장이 전부 `/app/tests/[id]?step=3` 같은 다른 영역의 깊은 페이지로 들어간다. 같은 페이지에 부모가 3~4개라 [←] 가 어디로 가야 하는지 정할 수 없고, 화면 위계가 안 잡힌다.
6. **단어장을 합칠 수 없다** — 교재 두 권을 한 시험 범위로 쓰려면 파일을 합쳐 다시 올려야 한다. 같은 파일 재업로드는 v4.7 에서 막았지만 병합은 없다.
7. **오늘(허브)이 자식 페이지로 직행** — `/app/tests/new` 같은 깊은 화면으로 바로 보내 "시험 탭" 을 건너뛴다.

## 3. 권장 부모/자식 IA

원칙: **사이드바 = 1차 영역 6개 (+관리 3개)**. 영역 안에서는 `부모(목록) → 자식(상세) → 손자(상세 안의 작업 화면)`. 다른 영역으로는 **텍스트 링크 "→ ○○ 탭"** 으로만 가고, 그것도 부모(목록)까지만 (필터 파라미터는 허용).

```text
오늘  /app                                  허브. 각 모듈은 "그 영역의 부모"로만 간다 (필터 허용)

학생  /app/students                         명단 · 반 · 등록 · 반 코드
      └ /app/students/[id]                  학생 상세 (추이 · 이력 점수 인라인 · 반복 오답 → 재시험 즉시 출제 · 정보 · 담당)
                                            이력 행은 점수·통과·틀린 수를 그 자리에서 보여준다. "→ 성적 탭에서 응시 상세" 텍스트 링크 1개

단어장 /app/vocabulary                      업로드 카드 · 단어장 카드 [열기] [시험 만들기] [보관] · 카드 다중 선택 → [병합]
      ├ /app/vocabulary/[bookId]            단어장 상세 = 검수·정리 화면.  ① 원본 ② DAY 나누기(펼침) ③ DAY 탭 + 단어 표
      │                                     우측 상단 검정 [시험 만들기] 없음. 하단 동작 바 [이 단어장으로 시험 만들기 →] 하나 (보고 있던 DAY 가 미리 선택)
      │                                     "이 단어장으로 만든 시험" 은 요약(제목 · 완료/대상 · 평균)만, 링크는 "→ 시험 탭" 하나
      │   └ /app/vocabulary/[bookId]/new-test   단어장 고정 출제 (단어장 이동 불가): 1 DAY 범위 → 2 대상 → 3 조건 → 4 이름·공개 → [출제]
      ├ /app/vocabulary/merge?ids=a,b       병합: 순서 · 새 제목 · 겹치는 단어 미리보기(제거 수) · DAY 처리(이어 붙이기 / 다시 7일) → [병합] → 새 단어장 상세
      └ /app/vocabulary/imports/[id]        업로드 상태 (지금의 /app/imports/[id], 경로만 단어장 아래로)

시험  /app/tests                            목록 (필터: 진행 중 · 마감 지남 · 초안 · 보관 · 단어장별) · 우측 상단 [+ 시험 만들기] · 카드 [사진 채점]
      ├ /app/tests/new                      순차 위저드: 1 단어장 선택 → 2 DAY 범위 → 3 대상 → 4 조건 → 5 이름·공개 → [출제]  (한 단계씩, 이전/다음 동작 바)
      ├ /app/tests/[id]                     시험 상세 = 진행 화면 (발행 후): 요약(대상 · 완료 · 평균 · 통과율 · 미달 n) + 학생별 표 · [마감 변경] · [종이 시험지] · [정답 공개]
      │                                     초안이면 "검토 후 발행" 카드 하나 (→ items). 성적은 이 화면 안에 요약, "→ 성적 탭" 텍스트 링크
      │   ├ /app/tests/[id]/items           문항·정답 (버전 · 경고 · 정답 정정 · 교사용 정답지 PDF · 초안 발행)
      │   └ /app/tests/[id]/targets         응시 대상 추가·제외 (시작 지금/예약 · 마감)
      └ /app/tests/scans                    사진 채점 (지금의 /app/scans)
          └ /app/tests/scans/[id]           판독 검토

성적  /app/results                          위젯 보드 · 학생별 요약 · 시험별 상세 — 시험/반 **선택 즉시 렌더** ([조회] 없음)
      └ /app/results/[attemptId]            응시 결과 (재채점 · 무효 · 오답노트 PDF). 부모는 성적 하나

재시험 /app/retakes                         큐 (출제 전 · 응시 대기 · 이번 주). 줄마다 원 점수 · 틀린 수를 인라인, [재시험 출제] 그 자리에서
                                            "→ 시험 탭", "→ 학생 탭" 텍스트 링크만

관리  /app/teachers · /app/billing · /app/settings   (그대로)
```

없어지는 것: 단어장 상세의 우측 상단 검정 [시험 만들기] · DAY 섹션의 [이 DAY로 출제] · 시험 상세의 3단계 탭 · 성적의 [조회] · 오늘의 `/app/tests/new` 직행 · 영역 간 카드 버튼 링크(`?step=3#due` 류).

## 4. 각 버튼 클릭 시 이동 경로

기호: ↓ 자식으로 · ↑ 부모로 · ● 그 자리에서 실행 · → 다른 영역(텍스트 링크, 부모까지만)

| 화면 | 버튼 | 이동 / 동작 |
|---|---|---|
| 오늘 | 이번 주 모듈 · 주의 반 [상세] · 선생님 [ALL] · 단어장 필 · 재시험 필 · 미응시 필 | → `/app/results` · `/app/students?group=class&pick=` · `/app/teachers` · `/app/vocabulary` · `/app/retakes` · `/app/results?filter=overdue` (모두 영역 부모) |
| 단어장 목록 | 업로드 카드 [업로드 · 자동 저장] | ● 업로드 → ↓ `/app/vocabulary/imports/[id]` → 끝나면 ↓ 단어장 상세 |
| | 카드 [열기] / 제목 | ↓ `/app/vocabulary/[bookId]` |
| | 카드 [시험 만들기] | ↓ `/app/vocabulary/[bookId]/new-test` (단어장 고정) |
| | 카드 [보관]/[복원] | ● |
| | 카드 체크 2개↑ → 하단 바 [병합] | ↓ `/app/vocabulary/merge?ids=` |
| 단어장 상세 | ← Words · 단어장 | ↑ 목록 |
| | 제목 [EDIT] · DAY 나누기 [적용] · 단어 [수정][출제 제외][삭제] | ● |
| | DAY 탭 | ● (같은 화면, `?day=`) |
| | 동작 바 [이 단어장으로 시험 만들기 →] | ↓ `…/new-test?day=<보던 DAY>` |
| | "이 단어장으로 만든 시험" 요약 하단 → 시험 탭 | → `/app/tests?bookId=` |
| 단어장 고정 출제 | ← 단어장 이름 | ↑ 단어장 상세 |
| | 단계 이전/다음 · [출제] · [초안만 저장] | ● / 출제 후 → `/app/tests/[id]` (시험 영역의 상세로 이동 — 만들어진 객체가 시험이므로 여기서만 영역이 바뀐다) |
| 병합 | ← 단어장 | ↑ 목록 |
| | [병합] | ● 새 단어장 생성 → ↓ `/app/vocabulary/[newId]` |
| 시험 목록 | [+ 시험 만들기] | ↓ `/app/tests/new` (1단계 단어장 선택부터) |
| | 필터 칩 · 정렬 | ● |
| | 행 클릭 | ↓ `/app/tests/[id]` |
| | [사진 채점] 카드 | ↓ `/app/tests/scans` |
| 시험 만들기 위저드 | ← Tests | ↑ 목록 |
| | 1 단어장 고르기 → 다음 | ● 다음 단계 (단어장 확정, 이후 단계에서 바꾸려면 1로 돌아감) |
| | 이전/다음 · [출제] · [초안만 저장] | ● / ↓ `/app/tests/[id]` |
| 시험 상세(진행) | ← Tests | ↑ 목록 |
| | [마감 변경] · [정답 공개] · [종이 시험지 발급] · [zip] · 방식 초기화 | ● |
| | 요약 카드 · 학생별 표 | 표는 정보 (점수 · 통과 · 기한). 행 클릭 없음 |
| | [문항·정답 →] | ↓ `/app/tests/[id]/items` |
| | [응시 대상 →] | ↓ `/app/tests/[id]/targets` |
| | → 성적 탭에서 상세 | → `/app/results?examId=` |
| | 초안 상태의 [검토 후 발행] | ↓ items (거기서 ● 발행 → ↑ 상세) |
| 문항·정답 | ← 시험 이름 · 버전 칩 · [정답 정정] · [발행] · [정답지 PDF] | ↑ / ● |
| 응시 대상 | ← 시험 이름 · [대상에 추가] · [제외] | ↑ / ● |
| 사진 채점 | ← Tests · [업로드 · 판독] · 행 클릭 | ↑ / ● / ↓ `/app/tests/scans/[id]` |
| 성적 | 기간·그룹 세그먼트 · 시험/반 선택 | ● 즉시 렌더 (URL 파라미터 갱신) |
| | 상세 표 행 [점수] | ↓ `/app/results/[attemptId]` |
| | 학생 이름 · 시험 이름 | → `/app/students?q=이름` · `/app/tests?q=제목` (부모 + 필터) |
| 응시 결과 | ← Results · [재채점] [무효] [오답노트 PDF] | ↑ / ● |
| 학생 목록 | [학생 추가] · 엑셀 · 반 관리 · 일괄 바 | ● (같은 화면) |
| | 행 이름 | ↓ `/app/students/[id]` |
| 학생 상세 | ← Students · [저장] · [연결 해제] · 반복 오답 [재시험 출제] | ↑ / ● |
| | 이력 행 | 정보 (점수 · 통과 · 틀린 수 인라인). → 성적 탭 텍스트 링크 1개 |
| 재시험 | 큐 줄 [재시험 출제] · 일괄 출제 · [취소] · 정렬 | ● |
| | 학생 이름 · 원 시험 | → `/app/students?q=` · `/app/tests?q=` |

## 5. 하단탭 / 사이드바 / 페이지 내부 버튼 구분

| 위치 | 역할 | 규칙 |
|---|---|---|
| **사이드바 (웹)** | 1차 영역 전환 | 오늘 · 학생 · 단어장 · 시험 · 성적 · 재시험 / 선생님 · 요금제 · 학원 설정. 항상 영역의 **부모(목록)** 로 간다. 깊은 페이지에서 눌러도 부모로. |
| **하단 탭 (모바일)** | 1차 영역 전환 | 오늘 · 학생 · 시험 · 설정. 성적은 학생 상세·시험 상세 안 (탭 아님). 단어장·재시험·사진 채점은 웹 전용 (PC 작업) |
| **페이지 머리 왼쪽 "← 부모"** | 상향 1단 | 모든 자식 페이지에 정확히 하나. 부모는 항상 같은 페이지 (여러 곳에서 들어와도 `?from=` 로 바꾸지 않는다) |
| **페이지 머리 오른쪽 검정 버튼** | 이 페이지의 **자식 만들기** 1개 | 시험 목록 [+ 시험 만들기] · 학생 [학생 추가] · 단어장 목록은 업로드 카드가 그 역할. 자식이 아닌 동작·다른 영역 링크는 여기 두지 않는다 (단어장 상세의 [시험 만들기] 를 없애는 이유) |
| **하단 동작 바 (검은 알약)** | 흐름의 다음 한 걸음 | 출제 위저드(이전/다음/출제) · 단어장 상세([이 단어장으로 시험 만들기 →]) · 병합([병합]). 한 화면에 하나, 주 동작은 맨 오른쪽 |
| **카드 안 버튼** | 그 자리에서 끝나는 동작 (●) | 마감 변경 · 발행 · 정답 공개 · 보관 · 저장 · 재시험 출제 · DAY 나누기 적용. 페이지 이동 없음 (성공 토스트 + 갱신) |
| **목록 행 / 카드 클릭** | 하향 (↓ 자식 상세) | 단어장 카드 → 단어장 상세, 시험 행 → 시험 상세, 학생 행 → 학생 상세, 성적 점수 → 응시 결과 |
| **텍스트 링크 "→ ○○ 탭"** | 영역 간 이동 (예외) | 카드 버튼 모양 금지. 항상 그 영역의 부모(목록)까지만, 필터 파라미터(`?examId=`, `?q=`)로 맥락 전달. 한 카드에 최대 1개 |
| **세그먼트 · 칩 · 정렬** | 같은 화면의 상태 | URL 파라미터로 반영 (뒤로가기 가능), 서버 왕복 시 [조회] 버튼 없이 즉시 |

### 구현 중 잡은 결함

- **위저드 [다음] 이 초안을 만들던 버그**: 조건 → 이름으로 넘어가는 순간 React 가 같은 자리의 `[다음]`(type=button) DOM 을 `[초안만 저장]`(submit) 으로 재사용해, 클릭의 기본 동작이 폼을 제출했다. 버튼에 `key` 를 두고 `preventDefault` 로 막았고, 회귀 체크를 E2E 에 넣었다.
- **Enter 제출**: 시험 이름 칸에서 Enter 를 치면 폼의 첫 submit 버튼([초안만 저장])이 눌린 셈이 되어 출제 대신 초안이 생겼다. 출제 폼은 Enter 로 제출하지 않는다 (아래 바 버튼으로만).
- 단어장 상세 `TESTS` 수가 최근 30개까지만 세던 것 → `_count.exams`.
