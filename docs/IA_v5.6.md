# 단어방 v5.6 IA: 출제 · 마감 · 휴지통 · 태그 · 성적 기준

이번에 받은 요청을 한 구조로 묶은 결과입니다. 원칙은 세 가지입니다.

- **상태는 한 곳에서만 바꿉니다:** 마감은 날짜를 누르면 바로 달력이 열리고, 출제는 하단 [출제하기] 한 번으로 끝납니다.
- **"보관"은 없앴습니다:** 모두 휴지통입니다. 휴지통 안에서만 영구 삭제를 할 수 있습니다.
- **설명 문구는 두지 않습니다:** 라벨과 상태 배지, 결과 토스트로 충분합니다.

## 1. 시험

```
시험
├─ 목록 탭: 미완료 · 마감 지남 · 완료 · 초안 · 🗑 휴지통 · 전체
│   ├─ 미완료 = 진행 중 · 시작 예약 · 출제 전(대상 없음). 마감 지난 시험은 넣지 않는다
│   ├─ 마감 열: 날짜 버튼 → 달력 팝오버 → [마감 변경] (안 친 학생 전체 · 학생 알림)
│   │    · 마감 지남 탭에서는 같은 팝오버가 "마감 지난 학생"에게 적용
│   ├─ 행 끝 🗑 → 휴지통으로 (확인)
│   └─ 휴지통 탭: [복원] · [영구 삭제] (배정·응시·답안·성적·시험지·재시험 모두 삭제, 확인)
└─ 시험 상세 (진행 · 문항·정답 · 응시 대상 · 성적↗)
    ├─ 대상 0명(출제 전): 진행 탭 = 대상 고르기
    │    반 칩(반 전체 체크) · 학생 체크 목록 · 시작(지금/예약) · 마감
    │    하단 고정 바: "N명 선택 · 9/28 23:59 마감" [출제하기 · N명]
    │    → 성공: 상단 "✓ N명에게 출제했어요" 배너, 상태 배지 '출제 전' → '진행 중'
    ├─ 대상 있음: 지금 화면 그대로 (완료·평균·통과율·미달 → 학생별 → 기간·공개·인쇄)
    ├─ 응시 대상 탭: 현재 대상 표 + 같은 대상 고르기(추가 출제) + 하단 [출제하기]
    └─ 머리 오른쪽 🗑 (휴지통으로)
```

## 2. 재시험 (행 하나)

```
[☐] 시험명 · 점수 · 틀림 n   [출제 전]
    [오답만 n | 같은 범위 m]  [마감 📅 9/28 23:59]  [출제]  재시험 없이 종료
```

- **조정 버튼은 없습니다:** 범위와 마감을 행에서 바로 고릅니다.
- **학생 그룹 머리:** [n건 한 번에 출제]는 그대로 둡니다.

## 3. 단어장

```
단어장
├─ 태그 줄: 전체 · #고1 · #모의고사 … · 태그 없음 · [+ 태그]
│    태그를 고르면: ✎ 이름 바꾸기 · 🗑 태그 지우기 (단어장은 남음)
├─ 카드: 제목 · #태그들 · 단어 수 · [시험 만들기] [병합] [⋯]
│    ⋯ : 태그 (체크박스 · 여러 개) / 🗑 휴지통으로
└─ 🗑 휴지통 n (접힘): [복원] · [영구 삭제]
     영구 삭제: 이 단어장으로 만든 시험 n개와 그 성적까지 삭제 (확인)
```

- 태그는 폴더와 달리 한 단어장에 여러 개 붙일 수 있습니다(`VocabBookTag`).
- 병합으로 만든 단어장은 원본 단어장 id를 기억합니다(`VocabBook.mergedFrom`).

## 4. 성적

```
성적
[요약 | 학생별 | 학교별 | 학년별 | 반별]  ‹ [항목 칩 …] ›            [단어장: 전체 ▾]
```

**기준:**

- **요약:** 위젯 보드입니다(항목 칩 없음).
- **학생별:** 칩은 학생입니다. 고르지 않으면 학생 요약 표, 고르면 그 학생의 응시 기록(시험·점수·결과)을 보여 줍니다.
- **학교별 · 학년별 · 반별:**
  - 칩은 선생님이 등록한 학교 · 학년 · 반입니다.
  - 고르지 않으면 그룹 표(학생 수 · 평균 · 통과율 · 추세 · 재시험)를 보여 줍니다.
  - 고르면 그 그룹의 숫자 4개, 추이, 학생 표를 보여 줍니다.

**항목 칩:**

- 가로 한 줄에 둡니다. ‹ › 버튼은 한 화면 폭씩 넘깁니다.

**단어장 필터:**

- 반별 · 학교별 · 학년별 · 주간 그룹과 이번 주 · 4주 · 12주 기간 선택은 모두 없앴습니다.
- 단어장을 고르면 그 단어장으로 만든 시험의 성적만 봅니다. 기간은 전체입니다.
- 병합한 단어장을 고르면 원본 단어장으로 만든 과거 시험까지 포함합니다. 이 규칙은 거꾸로 거슬러 올라가며 반복 적용합니다.
- 전체를 고르면 최근 12주로 봅니다(추이 그래프 기준).

**미응시 · 기한 경과 (`?filter=overdue`):**

- 상태 열의 [미응시] 버튼을 누르면 "마감기한을 늘릴까요?"와 달력이 열립니다.
- [늘리기]를 누르면 마감이 바뀌고, 시험이 다시 활성화되고, 학생에게 알림이 갑니다.

## 5. 학생 상세

```
숫자 3칸
단어장 진도 (새 카드)
  단어장명 ────────────── 3 / 7 DAY · 43%   다음: DAY 17
  [■■■□□□□]  (DAY 칸: 통과=진함 · 미달=빨강 · 배정만=회색 테두리 · 안 함=빈칸)
재시험 · 반복 오답 · 시험 이력 · 추이 · 정보(접힘)
```

- **진도 계산:** 학생이 친 시험(응시 확정)의 범위 DAY를 합칩니다.
- **다음 DAY:** 마지막으로 친 DAY 다음, 아직 치지 않은 첫 DAY입니다.

## 6. 지우는 설명 문구 (예시)

- 체크하면 여러 명을 같은 범위·마감으로 한 번에 낼 수 있어요.
- 위젯은 편집에서 옮기고·키우고·빼고·넣을 수 있습니다.
- 제목은 파일 이름 그대로 · 나중에 바꿀 수 있어요
- 그 밖에 화면 설명용 muted 문단 · 입력 힌트 문장
