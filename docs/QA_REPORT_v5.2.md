## 2. QA 리포트 P1

| # | 항목 | 반영 |
|---|---|---|
| 1 | 로그인 상태에서 `/login` 500 | 쿠키를 굽는 `landingAfterLogin` 을 페이지에서 부르지 않고 Route Handler `/api/auth/landing` 로. `/switch?to=` 와 `requireAcademy` 의 자동 선택도 `/api/auth/switch` 로 |
| 2 | 학생 탭 반 칩 = 반 전체 인원 | 칩 = **담당 학생 수**(학원장은 전체), 0명 반은 흐리게 + 툴팁. 빈 상태 문구는 담당/검색/반 필터에 따라. INVITE 카드는 필터 반과 동기화. 반 보관·삭제는 학원장만 |
| 3 | 러너: 준비 화면 없이 타이머 · 되돌리기 불가 | 준비 화면(문항 수 · 초/단어 · 규칙 · 이어서 풀기 안내) → [시작] → 3·2·1 → 첫 단어. 고른 뒤 0.4초 안에 다른 보기를 누르면 바뀜. 시간 초과는 빨간 플래시 + "시간 초과 · 놓쳤어요" + 진동 |

### DB 변경
`BookFolder` 테이블, `VocabBook.folderId` — `pnpm run db:push`(= `start-server.bat`) 가 기존 DB 에 자동 추가. `prisma/init.sql` 재생성, `db-init.ts` 는 새 컬럼 인덱스 때문에 init.sql 을 두 번 적용하도록 보강. 클라이언트 재생성은 `PRISMA_SCHEMA_ENGINE_BINARY=$(which true) PRISMA_ENGINES_CHECKSUM_IGNORE_MISSING=1 npx prisma generate` (엔진 다운로드 없이).
