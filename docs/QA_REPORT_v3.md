## 3. 새 화면

- **학원장 홈 (학원 현황)**: 이번 주 평균·통과율 링·요일별 응시, 주의 반(통과율 최저) 카드, 선생님별 평균, 결과 구성 도넛, 8주 추이, 단어장 필.
- **선생님 홈 (오늘 할 일)**: 오늘 진행률, 이번 주 대표 시험 남은 인원, 담당 학생 평균·추세, 재시험 큐, 사진 검수·미응시, 다음 보강.
- **학생 탭 = 그룹 대시보드**: 반별/학교별/학년별/선생님별/주간 × 이번 주/4주/12주. KPI, 그룹 막대(클릭 → 그 그룹 학생 목록), 점수 분포, 주간 추이, 학생×주 응시 히트맵, 워치리스트, 학생 목록(평균·최근·추세·재시험).
- **학생 상세**: 12주 추이(통과 기준선), 반복 오답 → "이 n개로 재시험 만들기"(즉시 발행·배정), 보강 일정 카드(날짜 변경), 이력.
- **단어장**: 업로드 → 자동 저장 → 단어장 화면의 **DAY 나누기**(일수 기본 7 / 단어 수 / 지문별 / 문서 표기) + 미리보기 막대 + 적용. 수동 단어 추가 제거, 잘못 읽힌 줄은 목록에서 인라인 수정·제외.
- **시험 출제 1화면**: 범위(DAY 칩) → 대상(반 칩, 여러 반) → 문항/통과/마감 프리셋 → 미리보기(다시 섞기) → "발행 · n명 배정 · 학생 앱에 표시". 제목 자동.
- **재시험·보강**: 큐(점수·오답 수·일정) + 14일 보강 캘린더. 오답만/같은 범위 재출제(즉시 발행·배정) → 보강 일정(날짜·시간·메모) → 학생 앱 재시험 탭(달력·보강 카드·틀린 단어) 표시 → 통과 시 완료.

## 6. v3.1 — 모션·상호작용 (2026-09-22 추가)

- **진입 모션**: 새 탭·새로고침·화면 전환마다 KPI 숫자가 0에서 굴러 올라가고(`CountUp`), 링·도넛은 채워지며, 막대(펄스·가로·세로)는 자라나고, 추이 선은 그려지며 점이 뒤따라 찍힌다. 히트맵 칸은 순서대로 떠오르고, 벤토 모듈은 차례로 올라온다. `prefers-reduced-motion` 이면 모두 즉시 표시.
- **담당 학생 자동 전환**: 선생님 홈의 담당 학생 목록은 6명씩 보여주고 6초마다 다음 묶음으로 넘어간다(호버 시 정지, 점으로 직접 이동).
- **히트맵 칸 클릭**: 학생 × 주 칸(빨강 포함)을 누르면 그 주 가장 낮은 점수의 시험 결과 화면으로 이동.
- **업로드 카드**: "파일 올리면 끝" 옆 ⓘ 호버 툴팁에 지원 형식·자동 분할 안내를 분리. 드롭존(끌어다 놓기·클릭, 파일명·용량·형식 표시, .hwp 경고) + 새 단어장/기존에 이어 붙이기 세그먼트 + 파일 선택 전 비활성 버튼.
- **정렬**: 성적 표의 점수·확정 헤더, 재시험 큐의 점수순·오답순·일정순, 학생 목록의 평균·최근·추세·재시험 헤더를 누르면 오름차순 → 다시 누르면 내림차순.
- 브라우저 QA 29/29, E2E 18/18, 연동 E2E 14/14.
