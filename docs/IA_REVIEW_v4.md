## 5. v4.3 — 결제 분리(체험) · 휴대폰 인증번호 가입 · OCR 단어장 · 시험 상세 3단계 (2026-09-22 추가)

## 6. v4.4 — 출제 흐름 IA/UX · 재시험 개편(보강 제거) · 성적 가변 위젯 · 종이 QR 채점 규칙 · 반응형 (2026-09-23 추가)

| 항목 | 내용 |
|---|---|
| 출제 흐름 (IA·UX QA) | 출제 화면 4개 섹션을 **번호 동그라미 + 제목 + 한 줄 힌트**(`StepHead`)로 통일하고 설명을 짧게 줄였다. **다음 동작 바**(`ActionBar`, 검은 알약)를 출제 화면과 시험 상세 3단계에 같은 자리(내용 하단, 화면에 붙어 따라옴)·같은 크기로 두어 주 동작(출제 / 다음 / 성적 보기)이 항상 **오른쪽 끝, 같은 폭**에 온다. e2e-retake ⑨가 두 화면의 주 버튼 오른쪽 좌표가 같은지 검사 |
| 성적 대시보드 | **선생님별** 그룹 탭 제거, 학생별 요약의 **계정(LINKED)** 열 제거. 위젯 보드(`WidgetBoard`, 12열 그리드): **위젯 편집** → 제목을 끌어 옮기기, 오른쪽 아래 모서리로 크기 조절, ✕ 로 빼기, 팔레트에서 넣기, 기본 배치로. 배치는 사용자별 `AcademyMember.dashboardLayout` JSON 으로 저장. 위젯 10종: 평균 점수(지난 기간 비교) · 통과율(비교) · 재시험(출제 전 n) · 미응시 · 그룹별 평균 · 성적 추이 · 점수 분포 · 누가 언제 봤나 · 챙겨야 할 학생 · 최근 시험. 제목·힌트를 쉬운 말로 |
| 재시험 (보강 제거) | `RetakeTask` 재구성: `scheduledAt/note` 제거, `kind`(failed/weak_words) · `mode`(wrong/same/words) · `wordIds` · `issuedAt` 추가, `sourceAttemptId` NULL 허용. 상태 `pending(출제 전) → issued(출제됨) → completed`. 재시험 화면: 행마다 **[오답만 n | 같은 범위 N] 토글**(고른 쪽이 검게, 아래에 "틀린 단어 n개만 · n문항" 요약) + **마감** + **재시험 출제** → 시험 생성·발행·그 학생에게 배정(마감)·**학생 알림**. 체크해서 여러 명 한 번에. 출제 뒤 마감 변경·시험지·결과 링크. 통과하면 완료(점수), 미달이면 그 응시를 원 응시로 하는 **2차** task 가 자동으로 이어진다 |
| Today | Retake 카드가 **마감 날짜별 묶음**(출제 전 n건 → 9/24 마감 · 이름들 → 마감 없음)으로, Next retake due 카드는 가장 가까운 마감 |
| 학생 앱 | 재시험 탭: 달력·보강 문구 없음. **Next 카드**(범위 종류·문항 수·지난 점수·마감·D-day·시작) → 틀린 단어 연습 → Up next(마감 순) · 준비 중 · 지난 재시험(점수). 홈 Retake 필은 가장 가까운 마감 |
| 학생 상세 | Weak words 에 **마감** 입력 + "이 n개로 재시험 출제" → 배정 단계 없이 그 학생에게만 즉시 출제(kind=weak_words) → 재시험 화면·학생 앱·알림에 바로. 보강 일정 카드 → **재시험 현황**(마감·응시 중·통과/미달, 마감 변경) |
| 점수 | 성적 상세 KPI 의 첫 응시/재시험 분리: 재시험 시험(isRetake)은 첫 응시 평균에 섞이지 않고 **재시험 통과율**에 잡힌다 |
| 학생 명단 표 | **담당·계정·상태** 열 제거 → 이름·학교 / 반 / 휴대폰(미가입이면 "가입 전"·"인증번호 보냄" 작은 글씨) / 4주 평균 / 재시험 |
| 종이 QR (학생 채점) | 시험지 우측 상단 QR → `/q/:token`. **제출 전**: 시험지 주인 학생 본인이면 카메라가 바로 열려 사진 제출 → OMR 채점 → 결과. 담당 선생님(또는 학원장)은 대신 찍어 채점. **다른 계정은 차단**("다른 계정으로 로그인"). 로그인 전이면 본인 비밀번호(=본인 로그인). **채점 후**: 본인·담당 선생님은 결과 바로, 그 외는 비밀번호. 비밀번호 확인이 다른 계정의 세션을 바꾸지 않음 |
