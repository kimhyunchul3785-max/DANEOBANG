# 단어방 — MVP 범위 · 완료 기준 · 검증 결과

버전: 3.0 · 기준일: 2026-09-22 · 연결: `PRD.md`, `TECH_STACK.md`

## 1. MVP 정의

서로 다른 학원이 각자 개설한 공간에서, 선생님이 검수한 단어로 실제 시험을 운영하고, 온라인·종이 성적과 재시험·오답을 데이터베이스에 남기는 첫 실사용 버전. 완료 사이클:

**학원 개설 → 선생님 초대 → 학생 명단/계정 연결 → 파일 등록·검수 → DAY 선택·사지선다 생성 → 발행·배정 → 온라인 또는 종이 응시 → 채점 확정 → 성적·재시험 → 정답 표시 오답노트.**

## 3. 검증 명령

```
npm run test:parsers   # HWPX/DOCX/PDF 추출 + 거부 케이스
npm run test:omr       # PDF 렌더 → 이미지 → 마킹 합성 → 판독 (회전·어둡기 포함)
npx tsx scripts/e2e.ts # 브라우저 E2E (서버 실행 + Playwright 필요, 17단계)
```

E2E 17단계 결과: **PASS** (2026-09-22, Linux 컨테이너, Chromium 141). Windows 실행 환경에서는 `start-server.bat` 로 서버를 띄운 뒤 동일 시나리오를 수동으로 재현할 수 있다.

## 5. 출시 차단 조건 (변경 없음)

다른 학원/학생 데이터 유출, 미공개 정답 유출, 답안 유실, 반복 제출로 이중 성적, 잘못된 학생 연결, 사진 불확실을 자동 오답 처리, HWP/스캔 분석을 가짜 성공으로 대체, PDF와 manifest 불일치, 복구 불가. 공개 출시 전에는 AC29 실물 검증과 M16 을 완료해야 한다.

## 6. 다음 단계 제안

1. 실제 학원 HWPX/DOCX 5~10종으로 추출 품질 측정 → 어댑터 보강.
2. 프린터 2종·휴대폰 3종으로 100페이지 실물 OMR 검증 → 임계값 조정.
3. Google/Kakao 콘솔 등록 후 `.env` 키 입력 → 소셜 로그인 실연동.
4. Expo 앱: `/api/v1` 클라이언트 + `expo-auth-session` + Secure Store, 선생님 현장용(오늘·학생·시험·사진 업로드) 화면.
5. PostgreSQL 전환(`provider = "postgresql"`, `@prisma/adapter-pg`), S3 파일 저장, 배포(Vercel/ECS).
