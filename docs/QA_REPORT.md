## 6. 연동 E2E 시나리오 (`scripts/e2e-linked.ts`, 13단계)

1. 학원장 로그인 → 학원 선택 화면(2곳) → 테스트학원 진입
2. 학원장 로고 등록 → 사이드바·`/api/files/logo/current` 반영
3. 학원장 화면에서 선생님1 구성원·학생01 연결/담당 확인
4. 선생님1 로그인 → 즉시 대시보드(담당 5명)
5. 선생님1 시험 만들기 한 화면으로 발행 + A반 5명 배정
6. 학생01 로그인 → 즉시 `/learn`, 이번 주 단어 테스트 + 방금 배정된 시험 표시
7. 학생01 응시(9/10) → 90점, 정답 미공개 확인
8. 선생님1 대시보드·성적에 즉시 반영
9. 학원장도 같은 결과 조회
10. 학원장이 학생02 종이 시험지 발급 → v2 레이아웃·로고 포함 PDF
11. 선생님1 정답 공개 → 학생01 오답 1개·오답노트 PDF
12. 선생님2(B반)는 학생01 목록·결과 접근 차단(404)
13. 조작 로그 파일에 action/api/client/page/job 기록 확인
